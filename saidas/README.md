# saidas/ — documentos pontuais do Workfoli

Pasta pra tudo que não é marketing (não cabe em `marketing/`).

## O que vai aqui

- **Análises** do `/analisar-dados`: resumos executivos de CSV, planilha ou PDF
- **E-mails** rascunhados pelo `/email-profissional`, quando você pede pra guardar
- **Relatórios diversos** que não são de anúncios
- **Documentos** que as skills geram pra você enviar, imprimir ou anexar

## Estrutura sugerida

```
saidas/
├── analises/        relatórios do /analisar-dados
├── emails/          rascunhos do /email-profissional
└── outros/          o que não se encaixa acima
```

As skills sabem onde salvar e criam as subpastas quando precisam.

## Por que separar de `marketing/`?

`marketing/` é o histórico vivo do marketing: peças, campanhas, SEO acumulado.

`saidas/` é o que foi gerado para hoje: o relatório que vai pro cliente,
o rascunho de e-mail que você copia e cola.

Propostas comerciais do `/proposta` ficam na pasta indicada pelo seu
perfil (`propostas/` ou dentro da pasta do cliente), não aqui.

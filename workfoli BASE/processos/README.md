# processos/ — como a empresa trabalha

Um arquivo por processo: atendimento, vendas, entrega, pós-venda, rotinas da equipe, aprovações.
O objetivo é que qualquer pessoa (ou agente) execute do mesmo jeito sem perguntar de novo.

## Modelo de arquivo

```markdown
# [Nome do processo]

**Quando acontece:** [gatilho]
**Responsável:** [função, não nome pessoal quando possível]

## Passo a passo
1.
2.

## Ferramentas envolvidas
## O que nunca fazer
## Como medir se deu certo
```

Processos descrevem **como** trabalhar. Registros de pessoas (clientes, pacientes, contatos) ficam
na camada privada da instalação, nunca em Markdown desta pasta.

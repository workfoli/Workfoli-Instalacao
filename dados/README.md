# dados/ — área de entrada

Solte aqui qualquer arquivo que você quer que o Workfoli leia: CSV
exportado do Google Ads ou da Meta, planilha de vendas, PDF de contrato,
transcrição de reunião, print de relatório.

Skills como `/analisar-dados` e `/relatorio-ads` leem direto desta pasta.
Você solta o arquivo, chama o comando e recebe o resumo.

Aqui é entrada, não resultado. O que importa vira arquivo em `_memoria/`,
`marketing/` ou `saidas/`.

**Privacidade:** o conteúdo desta pasta não vai pro GitHub (só este
README). Dados de clientes ficam só na sua máquina.

Com conectores de armazenamento ativos (Google Drive, Notion), você também
pode pedir pro Claude buscar o arquivo direto na fonte, sem baixar nada.
